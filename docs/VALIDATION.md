# v0.1.0 验证记录

## 已完成（本次实际执行）

- TypeScript 5.8.3 编译和 `--noEmit` 类型检查通过。
- `node --check site/sw.js` 语法检查通过。
- 29 项 Node 测试通过：24 项账户/成交/参数/导入计算 + 5 项 service worker 逻辑仿真。
- Chromium 在 `about:blank` 中加载本项目自有 HTML/CSS/JS，完成 11 项 DOM 交互检查；无 JavaScript 运行异常。
- 视口检查覆盖 320、360、390、430、768、1440 像素宽度，四页未检测到水平溢出。
- 表单测试验证“已结算金额 > 总现金”被拒绝；卖出后持仓减少而已结算不增加；脚本样式输入作为纯文本显示；无效阶梯被阻止。
- 静态网站 7 个关键 HTTP 路由返回 200。
- manifest 所引用的图标尺寸和本地资源存在性检查通过。
- 真实浏览器渲染的截图（仅人工演示数据）位于 test-evidence。

## 本次环境限制

本执行环境的 Chromium 管理策略阻止所有网址导航。没有修改或绕过该策略。

因此界面测试通过 `page.set_content` 渲染自有代码，并对 localStorage 使用内存测试替身。它能检验布局、事件、表单和记录计算，**不能证明实际浏览器持久存储、service worker 注册、离线重载或手机安装已经成功**。

`tests/browser_smoke.py` 提供正常浏览器环境的待执行脚本，不计入已通过测试。离线回退目前只通过 service worker 的模拟逻辑测试。

## 部署后的必要验收

1. HTTPS 打开，manifest、JS、图标、sw.js 均成功加载；真实存储刷新后保留。
2. iPhone Safari / Android Chrome 添加到主屏幕，图标和独立窗口正确。
3. 首次联网打开完成缓存后，离线重开应显示离线标识并展示本机记录。
4. 导出 JSON → 备份文件存在且可读 → 清空 → 恢复；浏览器及主屏幕存储差异在用户设备核实。
5. 双标签页更新关闭旧编辑表单，避免覆盖。
6. 新版本明确提示更新；更新后旧数据保留。
7. 金额遮罩不被宣传为加密；关闭页面没有推送、后台分析或交易执行。
8. Vercel 路径和安全响应头与配置一致；实际是否构建/发布成功需要平台返回真实状态。

没有验证任何投资收益、胜率或市场预测。
